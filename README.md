# Sketchware PRO 7.0 Block Builder

Ferramenta leve para construir, validar e organizar blocos JSON voltados principalmente ao **Sketchware PRO 7.0**, utilizando o caminho padrão `/storage/emulated/0/.sketchware`.

## Como usar (`git clone`)

```bash
git clone [https://github.com/SEU_USUARIO/sketchware-pro7-block-builder.git](https://github.com/SEU_USUARIO/sketchware-pro7-block-builder.git)
cd sketchware-pro7-block-builder
